## Accessibility and lifecycle

The homepage Pause/Resume control coordinates the ribbon, particles, CSS entrances, and footer paper. Paused scrolling reveals necessary content immediately rather than hiding it. Resume catches the ribbon up to current scroll position. Reduced-motion mode disables entrances, reveals, particle updates, custom cursor/trail, and paper sway; shows all content and a static ribbon; and preserves normal pointer and keyboard interactions. Fine-pointer cursor behavior is never enabled on touch-only devices. Tab/Escape restores the normal cursor. Decorative elements are hidden from assistive technology.

The pointer is rendered in a body portal so the existing route-transition wrapper cannot offset viewport coordinates. Cursor listeners, GSAP contexts, ScrollTriggers, reveal tweens, observers, and ticker callbacks are cleaned up on navigation and media-query changes. Particle transforms stop updating offscreen or while the document is hidden. Trail rendering stops when its short-lived points expire. No proprietary media or reference HTML is part of the exported application.
